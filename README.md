These notebooks were used to run simulation, data processing, optimization and visualization for results published in ** Jamdade, S., Cai, X., Allen-Dumas, M.R., and Sholl, D.S. (2024). Incorporating Diurnal
and Meter-Scale Variations of Ambient CO2 Concentrations in Development of Direct Air
Capture Technologies. ACS Sustainable Chemistry & Engineering. **

** opt_cost.ipynb is a python file to run the gPROMS simulations for carbon capture process and optimize the carbon capture cost using pyomo

** opt_prod.ipynb is a python file to run the gPROMS simulations for carbon capture process and optimize the carbon capture productivity using pyomo

** Other python files are for data processing and visualization
